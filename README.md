# 保洁数字化评分系统 （Web 前端库）

欢迎大家来到 **保洁数字化评分系统** 的开发项目中！  
本项目旨在搭建一个完整的保洁质量评分与管理平台，支持从前端到后端再到移动端的全流程开发。  

## 项目结构
本项目主要分为以下三个板块：
- **Web 前端**：提供可视化界面，便于用户操作与数据展示  
- **后端服务**：负责业务逻辑处理与数据存储  
- **移动端 APP**：支持移动端的评分与管理功能，提升使用便利性
